# Liquid Glass 统一规范

## 原则与来源

依据 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars) 和 [Liquid Glass overview](https://developer.apple.com/documentation/technologyoverviews/liquid-glass)。玻璃用于内容上方的导航与控件层，页面正文保持原材质；以 regular 材质的可读性为目标，保持标签、原生角标与稳定导航。只采样内容，避免多层玻璃重复录制。Apple 的原则与下面的 Android 项目参数分开维护，不宣称像素复刻 Apple 私有实现。

本套几何与轻门、完美图标、GhostKey 既有 Compose/Miuix 导航标准对齐。原生宿主保留自身图标语义、字体和回调，适配器负责透明标题与内容居中，不把所有宿主强行换成相同图标。

## 项目参数

| 项目 | 统一基线 |
| --- | --- |
| 外壳 / 单元高度 | 64dp / 56dp，内边距4dp |
| 单项宽度 | 最小76dp，按内容扩展；两项160dp，三项236dp |
| 窄屏 | 两侧24dp；触摸区域至少48dp，不能缩小文字凑宽 |
| 图标 / 标签 | 图标参考24dp；标签11sp，跟随系统字体缩放，图文间距参考1dp |
| 大字体 | 单元高=max(56dp,24dp+1dp+标签高+12dp)，外壳再加8dp |
| 底部位置 | 实际导航栏 inset+8dp；没有 inset 时36dp；扣除父容器已避让部分 |
| 列表末项 | 按实际胶囊占用+底部间距+12dp避让 |
| 外壳材质 | 4dp模糊、1.5饱和度、40%主题容器色、24dp边缘透镜 |
| 选中透镜 | 10dp折射高度、14dp折射量乘按压进度；色散0.5；静止10%明暗选中底色 |
| 按压 | 78/56的选中透镜放大；图文视觉副本渐变到1.2倍 |
| 速度形变 | 横轴速度系数0.75，纵轴0.25；最大0.2 |
| 弹簧 | 位置1/1000、速度0.5/300、按压1/1000、横缩放0.6/250、纵缩放0.7/250（阻尼/刚度） |

透明和缩放是绘制层行为，原生按钮仍保留单一焦点、可访问性语义和点击。标签不得带不透明矩形，角标保留原色。选中、拖动、取消、快速反向、RTL 和系统关闭动画均纳入回归；系统关闭动画时关闭按压变形并直接跟随目标。

## 验收边界

深浅色、繁忙列表、列表末项、大字体与系统导航模式分别检查。纯 JVM 只能验证尺寸和状态轨迹，不能证明 GPU 观感、屏幕帧率或苹果像素等同。企业微信0.3.2已由用户确认可用；其他宿主和新增参数仍按实际测试结果更新，不把静态反编译当作运行验证。
